# Course maintenance

Read README.md and the current module before editing. The user is learning company diagnosis and portfolio reuse, not crypto. Keep examples fictional and independent of any employer. Do not insert invented company policies, user metrics, certifications, or approvals.

Curriculum source: site/course-data.js. Run npm run build after content changes. Run npm run check for behavior changes. Build output is site/; keep personal drafts and submissions out of the public course repo. Do not embed credentials or GitHub write tokens in browser code.

Completion is learner self-assessment and is not a verified reviewer grade. Opening a submission link must never mark work submitted. Import must validate and constrain untrusted JSON. Editing completed work should require reassessment.
